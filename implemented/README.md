# Implemented work log

This directory stores completed implementation notes and examples of work that has already been built.

## Purpose

Use this area to keep track of completed features and to reference finished implementations that may be useful as patterns for later work.

## Suggested workflow

- move a completed plan from plans/archive/ here once implemented
- record the feature name, date, summary, and any relevant validation notes
- keep this directory focused on outcomes, not raw planning drafts
